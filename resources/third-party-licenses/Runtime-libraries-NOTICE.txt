Additional runtime libraries shipped under
resources/app/bin/frankenphp/

These dynamic libraries come from the official FrankenPHP Windows release
archive. None of them is covered by
resources/app/bin/licenses/frankenphp/readme-redist-bins.txt, which attributes
only the
third-party code compiled INTO the PHP interpreter.
